## 精確解析規則

- `ML-WP-*`、`REP-*`、`PL-*`：教育部《數位時代媒體素養教育白皮書》，2023 年 3 月；分別指向媒體分析／公民參與、再現／多元觀點、數位平台／近用／產製章節。
- `AD-*`：依題意分別連到行政院消費者保護會「基本政策」、「電子商務消費者保護綱領」或食藥署食品廣告認定準則，不再落到機關首頁。
- `BULLY-*`：教育部 2024 年校園霸凌防制準則修正說明，網路霸凌、證據保存與校園處理程序。
- `TFC-*`：依題意連到台灣事實查核中心「查核準則及查核結果說明」或「六堂查證工具課」，不再落到網站首頁。
- `AI-*`、`MOE-AI-*`：教育部 AI 人才方舟現行版高級中等以下學校 AI 使用和學習指引與配套文件。

完整機器可讀欄位以 `src/source-registry.ts` 為準。100 個使用中的來源代碼採封閉清單登錄，未登錄代碼會直接報錯；測試同時確認「題庫使用集合＝登錄集合」，並逐題檢查文件名稱、具體主題、HTTPS URL 與查閱日期。

## 題庫品管規則

- 六卷各 25 題，共 150 個不同題幹與 ID。
- 公開 API 不輸出答案與解析。
- 答案位置在每卷內平衡，且不使用短週期循環。
- 正解位置不得出現可預測的短週期；正解與干擾項長度須混合分布，不得以「總是最長」或「總是最短」形成猜題線索。
- 每題四個選項不可重複，解析必須說明正確依據與錯誤選項限制。
- 題庫修訂時需同步跑自動測試，並抽查多重可接受答案、過時法規與歧視性表述。
