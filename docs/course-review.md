# 課程審查與版本紀錄

## 2026-08-27 安全與教學品質修訂

- 名稱由「認證 3 小時」調整為「三小時自學課程」，核發物明確標為本站課程完成證明。
- 六卷改為各自累積 25 分鐘，微教案區另累積 30 分鐘；不可用單一頁面掛機補足全部時間。
- 每卷新增時間配置、實作提示與必繳學習證據。
- 微教案新增最低內容品質、可觀察學生產出、分鐘流程、來源、個資與傷害風險檢核。
- 150 題改為獨立情境題，加入來源代碼、答案位置與選項長度防猜測測試。
- 新學員改用 HttpOnly、可撤銷工作階段與一次性輪替復原碼；保留舊版憑證的一次性安全升級入口。
- 管理端新增具名帳號、TOTP 雙因素驗證、伺服器端工作階段、登入限制與稽核紀錄。
- 新增註冊速率限制、通用重複帳號訊息、嚴格同源寫入、HSTS 與資料自行刪除功能。
- 補齊個資蒐集者、目的、類別、期間、地區、對象、方式、權利、不提供影響及聯絡方式。
- 補入官方白皮書、教育部霸凌資料、AI 指引、消保與查核來源。
- 複驗後統一 180 分鐘模型為六卷各 25 分鐘加微教案 30 分鐘，並把 25 題評量排入每卷腳本。
- 補入第四權、公共媒體、言論自由責任、公民近用、暗黑操作模式、精準投放、申訴、數位平權與公民產製正文，消除考未教。
- 移除題庫機械填充文字；正解與干擾項均保留完整判準，並打散答案位置與選項長度，避免最長、最短或短週期猜題線索。
- 100 個使用中的來源代碼改採封閉清單，逐題解析到八組具體官方文件／資源頁與主題欄位；未登錄來源代碼會拒絕建置。
- 核發完成證明前會重新解析並驗證六份結構化實作證據，不只檢查資料列是否存在。
- 新增每日 Durable Object alarm：自動刪除三年未活動學員、過期工作階段及逾期稽核／限制資料。
- 舊版 Bearer 憑證只能遷移一次；新增學員安全登出、30 天工作階段、校園 NAT 友善限流與復原碼錯誤限制。
